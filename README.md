## 🎯 Por que o Garden Docs?

Ferramentas como Word e Google Docs exigem contas online, enviam o conteúdo de seus textos para servidores externos e possuem interfaces pesadas cheias de barras desnecessárias.

O **Garden Docs** foi projetado para escritores, desenvolvedores e profissionais que precisam de foco:
* **100% Offline & Privado:** Seus documentos ficam salvos no seu próprio navegador via LocalStorage. Zero telemetria, zero nuvem.
* **Sintaxe Markdown & Toolbar Avançada:** Escreva rápido com atalhos de teclado ou utilize a barra de ferramentas para negrito, itálico, títulos H1/H2/H3, citações, listas, checklists, blocos de código e **inserção interativa de Tabelas Markdown**.
* **Suporte Completo a Tabelas GFM:** Renderização nativa de tabelas GitHub Flavored Markdown com alinhamento de colunas à esquerda, centralizado e à direita.
* **Exportação em 1 Clique:** Baixe o arquivo `.md` puro ou imprima/exporte direto como **PDF formatado** (`Ctrl + P`).
* **Métricas em Tempo Real:** Contador de palavras, caracteres e estimativa de tempo de leitura.
* **Multiplataforma:** Roda liso na Web e como APK nativo Android via Capacitor.

## 🚀 Deploy Web & Aplicativo Android (APK)

* **Web App (GitHub Pages):** [felipegardenghidev.github.io/garden-docs](https://felipegardenghidev.github.io/garden-docs/)
* **Download do APK Android:** A cada commit na branch principal, o GitHub Actions compila automaticamente o APK nativo através do pipeline Capacitor + Gradle e disponibiliza o artefato `garden-docs-debug-apk` para download direto na aba **Actions** do repositório, dispensando o Android Studio na máquina local.
